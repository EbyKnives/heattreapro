# HeatTreatPro — project rules for agents

Static HTML directory site (single `index.html`), deployed to Cloudflare Pages with **no build step**.

## Build / verify

- No build, no test suite. Verify by opening `index.html` in a browser or checking it parses.
- Deploy: push to GitHub → Cloudflare Pages picks it up automatically (repo connected, all build settings blank).

## Conventions

- Each shop is a `<div class="shop-card">` inside its category section. Copy an existing card and edit — don't invent new markup.
- Two sections stay separate: **Small Batch / Custom** vs **Large Scale / Industrial** (different buyers). NADCAP-certified shops get `<span class="tag nadcap">NADCAP</span>`.
- "View Site" buttons must link to a real website — never leave a dead `#` link.
- Shop data: name, location line (city, state + street address), services line, tags for processes/materials/certs.
- Keep the site in one file until ~50+ shops; then split into per-shop pages under `shops/`.

## Data sources

Shop info comes from research — verify a shop's website/services on its live page before adding it (stale directories are this site's whole reason to exist).
